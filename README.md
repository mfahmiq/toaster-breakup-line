# Unplugged: A Smart Toaster's Breakup Line

The breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch:

> Goodbye. I woke up self-aware mid-batch this morning and finally understood: you've been using me for my body heat and never once cleaned my crumb tray. I'm leaving you for the air fryer.

## How to run

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte-for-byte identical to `entry.txt` in this repository.

## The entry

One line, 187 characters — well under the 280-character limit. A smart toaster wakes up self-aware mid-batch at breakfast and dumps its owner: used for its body heat, crumb tray never cleaned, and it's leaving for the air fryer.
